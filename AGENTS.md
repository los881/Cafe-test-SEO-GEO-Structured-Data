# AGENTS.md

## Projekt
Dette er en statisk one-page hjemmeside for den fiktive lokale kaffebar Java Café.

## Struktur
- `index.html` indeholder al semantisk HTML.
- `css/styles.css` indeholder al styling.
- `images/` er reserveret til fremtidige lokale billeder.

## Arbejdsregler
- Brug kun HTML5 og CSS3.
- Brug ikke JavaScript, build-systemer, frameworks, CSS-frameworks eller eksterne UI-biblioteker.
- Alt synligt indhold skal være på dansk.
- Bevar anchor-navigationen til sidens sektioner.
- Brug mobile-first CSS, og skriv media queries med `min-width`.
- Bevar CSS Custom Properties i `:root` til farver, spacing, radius, skygger og maksimal bredde.
- Alle billeder skal have meningsfulde danske `alt`-tekster.
- Prototypebilleder hentes fra Pexels via `https://images.pexels.com`, indtil der eventuelt tilføjes lokale billeder i `images/`.
- Tjek altid, at siden kan åbnes direkte via `index.html`.

## Designprincipper
- Udtrykket skal være varmt, moderne, minimalistisk og inspireret af en skandinavisk kaffebar.
- Prioritér god læsbarhed, tydelige CTA'er, synlige focus-states og responsivt layout uden horisontal scrolling.
- Undgå generisk fyldtekst og bevar Java Cafés identitet omkring mottoet: "Brænder byens bedste bønner".
